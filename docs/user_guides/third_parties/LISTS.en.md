application and the licenses that apply to those components. These notices do
not apply to separately licensed commercial components or optional
development-only dependencies.

The license terms of each third-party component govern that component. The
installer provides the complete license text for each component in the
`ThirdPartyLicenses` directory next to this notice. The upstream URL is
retained below for source attribution and license updates.
