# 后处理定制

FiberArt 使用模板将轨迹点转换为设备程序。后处理器通常从仿真/后处理面板中选择，生成结果后应在目标控制器或仿真环境中再次检查坐标系、姿态、速度和 I/O 指令。

## 已提供的模板

当前版本包含以下常用模板：

- `KukaKRLLW`：Layway KUKA KRL 后处理器，支持按层号、线号和生成进度组织输出；
- `KukaKRLXR`、`KukaKRLFS`：KUKA KRL 输出模板；
- `KukaCNC`：KUKA CNC 输出模板；
- `CNC`、`XDCNC`、`XDAxisCNC`：含重送轴输出的 CNC 模板；
- `ToJson`、`ToPoses`：将轨迹导出为 JSON 或位姿数据，便于调试和与其他程序交换。

## CNC 重送轴

航点的 `registers.feed_position` 以米记录每道丝路的累计送丝指令位置。有通道处于重送时，它按 TCP 路径增量乘以重送速度比例累加，重送空闲时保持。`CNC` 将它转换为毫米并输出到 `E2`，`XDCNC` 和 `XDAxisCNC` 输出到 `W`。这些模板在每道丝路的起点输出 `G92`，将当前物理位置设为新坐标零点。

`XDCNC` 和 `XDAxisCNC` 使用 `M101` 启动程序、`M102` 结束程序、`M103` 开启加热和吹气、`M104` 关闭加热和吹气。默认切刀停留为 1 秒。控制器的指令和轴映射须与现场配置一致。

## 自定义模板

高级用户可以复制现有模板并按设备控制器语法修改。模板接收轨迹、机器人/变位机自由度、工具和程序信息，并可使用内置的位姿转换过滤器生成 KUKA 姿态、轴角或其他格式。

在 **仿真及后处理** 面板的导出区域可以直接管理本地后处理脚本。在线版本的安装、使用及移除见[仿真与导出](../user_guides/simulation.md)。

- **安装**：选择一个 `.py` 或 `.jinja` 脚本，复制到软件的后处理器目录并加入下拉列表；存在同名脚本时会先确认再覆盖；
- **编辑**：在内置编辑器中修改所选脚本，`.jinja` 模板带有 Jinja 语法高亮；
- **删除**：确认后从磁盘移除所选脚本并从下拉列表中删除。

自定义模板至少应确认：

1. 位置和姿态使用的坐标系与设备配置一致；
2. 姿态格式和角度单位符合控制器要求；
3. 起刀、铺放、切刀、加热等 I/O 指令与现场信号一致；
4. 轨迹边界、层号和线号不会被模板合并或丢失；
5. 输出文件已在离线仿真或控制器测试环境中验证。

KRL 输出默认会清理空行和多余空白，并在需要时拆分文件；模板可配置每个文件的最大行数。不要直接把未验证的程序发送到设备执行。
