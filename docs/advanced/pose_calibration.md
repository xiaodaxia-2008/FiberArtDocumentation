# 位姿与标定

## 位姿编辑

在编辑位姿、机器人属性或 TCP 标定时，可以在 **格式** 下拉框中选择旋转表示方式。当前支持：

- 欧拉角：内旋或外旋的 XYZ、XZY、YXZ、YZX、ZXY、ZYX 六轴序列；
- 机器人专用格式：**库卡 ABC**、**川崎 OAT**、**三菱 ABC**、**发那科 WPR**；
- **UR 轴角**表示；
- **四元数**表示，分量顺序为 `I, J, K, W`。

欧拉角、机器人专用格式和轴角的输入单位为度；四元数没有角度单位。切换格式时，软件会保持当前位姿并重新显示对应分量。

**复制** 会将位姿复制为 JSON，**粘贴** 可从剪贴板恢复一个七元素位姿。剪贴板内容必须是有效的位姿 JSON，包含位置和旋转数据。

## 默认姿态格式

位姿控件的默认格式为 `EulerIntrinsicXYZ`。如需统一团队使用的姿态表示，可在全局参数中设置 `GUI/DefaultPoseFormat`，填写上面列出的格式名称。工件位姿标定会使用该设置输出旋转结果；未设置或名称无效时使用 `EulerIntrinsicXYZ`。

## 工件位姿标定

打开 **工件位姿标定** 面板，在两张表中分别填写同一组特征点在工件坐标系和基坐标系中的坐标。

1. 两张表的点数必须相同。
2. 至少需要三组点对。
3. 可以使用 **添加行** 增加行，使用 **删除行** 删除选中行，使用 **清空** 清空表格，也可以直接从剪贴板粘贴点坐标。
4. 点击 **计算** 计算工件相对于基坐标系的位姿。

结果包含 X、Y、Z 平移和按默认姿态格式计算的旋转分量，并自动复制为 JSON 到剪贴板。四元数格式输出 `I, J, K, W`；其他旋转格式输出三个角度分量。

!!! warning "注意"
    进行标定前，请确认两张表中的点按相同顺序一一对应，并确认长度单位为米。

## TCP 标定

打开 **TCP 标定** 面板，录入至少三组不同的法兰位姿。每组位姿都可以使用上述格式编辑。点击 **计算 TCP** 后，软件显示 TCP 在法兰坐标系中的 X、Y、Z 坐标，并将结果 JSON 复制到剪贴板。
