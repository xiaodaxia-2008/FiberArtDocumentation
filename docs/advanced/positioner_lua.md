# Lua 自定义变位机策略

!!! note "适用版本"
    此功能自 FiberArt v0.25.1 起提供。

## 设置步骤

1. 打开 **仿真及后处理**，选择仿真组，并将工件挂在变位机之下。
2. 在运动学设置中选择 **规则联动（RuleBased）**。
3. 在 **变位机** 页签选择 **自定义函数（CustomFunction）**。
4. 点击 **编辑自定义函数**，填写 Lua，点击 **确定**。
5. 点击 **应用** 保存到当前轨迹，或 **应用到所有轨迹**。
6. 重新计算并检查仿真。

脚本随轨迹的求解参数保存。优化联动不采用此策略；启用“优先使用路径点关节值”时，有效的已保存路径点关节值仍优先。

## 函数接口

脚本必须返回一个函数：`function(pose, qseed)`。

| 参数/返回值 | 含义 |
| --- | --- |
| `pose` | 工件坐标系下的目标 TCP 位姿；`pose.x/y/z` 为米，另可读取 `rotation`、`matrix` |
| `qseed` | 仅包含变位机关节的 Vector；第一点取初始关节种子，后续点取上一次返回值 |
| 返回值 | 单元素 Vector，角度为弧度；Vector 从 1 开始索引 |

固定为 30°：

```lua
return function(pose, qseed)
    return Vector.from(math.rad(30))
end
```

保持初始角度：

```lua
return function(pose, qseed)
    return qseed
end
```

语法错误、运行异常、nil、维数错误和非有限数值会导致求解失败。变位机角度计算后，软件继续求解机器人补偿运动。

## 端头处突然旋转 180°

当曲面法线与旋转轴重合时，法线的横向投影消失，经过极点后反向，`Align` 可能给出相差 180° 的解。若径向分量也消失，单纯降低法线权重无法消除奇异点。

可根据已知轴向坐标划定端头过渡区，在进入端头之前开始旋转，离开端头之后平滑完成转角。**不能只按轴向坐标计算角度**：去程和回程经过相同轴向位置，需要结合横向位置、上一点角度或脚本状态区分两侧。角度应相对 `qseed` 连续展开，避免 +π/−π 跳变。只在极点保持上一点角度可能将跳变推迟到离开端头时。

接口不提供整条路径前瞻、时间或弧长。Lua 闭包状态仅在本次求解期间存在，下次求解重新建立。需按实际工件坐标系设置轴线、端头位置和过渡范围；没有适合所有安装方式的统一坐标公式。

角度连续不等于速度和加速度满足设备要求。过渡区应足够长，并检查机器人可达性、碰撞和外部轴运动；脚本返回的是角度，不是具有时间约束的运动曲线。
