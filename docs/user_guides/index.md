# FiberArt 自动铺丝软件用户使用文档

本文档提供`FiberArt`软件的使用指导，建议用户根据教程步骤，一边阅读，一边完成软件操作。

## 手册适用版本与更新基线

| 项目 | 当前覆盖范围 |
| --- | --- |
| 已发布版本 | FiberArt **v0.25.2** |
| 未发布功能 | 本轮无单独标注的未发布功能 |
| 已核对的 FiberArt 源码提交 | `f9689aed2581073bc0e5006c22fd282208301cdb` |
| 最近更新日期 | **2026-11-23** |
| 已知未补项 | 本轮核对范围内无已登记的待补功能说明；不代表所有旧页面均已逐项重验 |

每次更新手册时同步维护中英文此表。下次补充文档，从上述源码提交到目标版本比较用户可见改动，核对并补充操作说明后再推进基线；若有待补项，明确列出，不能仅因发布了新版本就修改覆盖版本。

!!! attention "版本差异"
