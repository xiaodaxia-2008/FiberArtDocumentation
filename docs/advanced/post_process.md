# 后处理定制

FiberArt 使用 Jinja2 模板将轨迹点转换为设备程序。后处理器通常从仿真/后处理面板中选择，生成结果后应在目标控制器或仿真环境中再次检查坐标系、姿态、速度和 I/O 指令。

## 已提供的模板

当前版本包含以下常用模板：

- `KukaKRLLW`：Layway KUKA KRL 后处理器，支持按层号、线号和生成进度组织输出；
- `KukaKRLXR`、`KukaKRLSubProg`、`KRLFS`：KUKA KRL 输出模板；
- `KukaCNC`：KUKA CNC 输出模板；
- `InovanceScan`：汇川扫描轨迹输出模板；
- `ToJson`、`ToPoses`：将轨迹导出为 JSON 或位姿数据，便于调试和与其他程序交换。

## 自定义模板

高级用户可以复制现有模板并按设备控制器语法修改。模板接收轨迹、机器人/变位机自由度、工具和程序信息，并可使用内置的位姿转换过滤器生成 KUKA 姿态、轴角或其他格式。

在 **仿真及后处理** 面板的导出区域可以直接管理后处理脚本：

- **安装**：选择一个 `.py` 或 `.jinja` 脚本，复制到软件的后处理器目录并加入下拉列表；存在同名脚本时会先确认再覆盖；
- **编辑**：在内置编辑器中修改所选脚本，`.jinja` 模板带有 Jinja 语法高亮；
- **删除**：确认后从磁盘移除所选脚本并从下拉列表中删除。

自定义模板至少应确认：

1. 位置和姿态使用的坐标系与设备配置一致；
2. 姿态格式和角度单位符合控制器要求；
3. 起刀、铺放、切刀、加热等 I/O 指令与现场信号一致；
4. 轨迹边界、层号和线号不会被模板合并或丢失；
5. 输出文件已在离线仿真或控制器测试环境中验证。

KRL 输出默认会清理空行和多余空白，并在需要时拆分文件；模板可配置每个文件的最大行数。不要直接把未验证的程序发送到设备执行。
