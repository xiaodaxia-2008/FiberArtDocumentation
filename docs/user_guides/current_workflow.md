# 当前版本工作流

本文按 FiberArt 0.22.0 的界面和功能整理。软件的核心工作流是：准备几何与设备模型，创建或规划铺层，检查铺层质量，配置运动系统，仿真并导出设备程序。

## 1. 创建工程与导入模型

1. 使用 **文件 > 打开** 打开工程或文件。在打开文件对话框中，按需要选择 **CAD 零件**、**CAD 装配体**、**CAD 单体**、**网格化曲面**、**模型**、**场景**、**节点** 等文件类型过滤器；也可以选择 **全部**，由软件根据文件扩展名识别类型。使用 **保存** 或 **另存为** 保存工程；启动后也可以从空白场景开始添加节点。
2. STEP/IGES、网格、场景节点以及其他插件支持的数据都通过 **文件 > 打开** 导入。**文件 > 导入 > 组件库** 打开组件库对话框：可以按 **类型**（机器人、轨道、位置机等）和 **品牌** 筛选，按 **名称** 搜索，或点击 **更新** 从云端获取最新组件目录；表格显示组件的型号、品牌、负载、臂展和安装状态，双击选中项或点击 **Open** 载入设备组件。
3. 打开设备模型（机器人、工具、导轨、位置机）时，软件会保留模型原有姿态并尝试自动挂载到场景中：机器人挂载到已有导轨下、工具挂载到已有机器人下，挂载顺序不影响最终的装配结果。
4. 在场景树中选择节点，双击打开属性编辑器；右键节点可以执行该节点支持的操作。
5. 对需要参与铺放计算的 CAD 曲面，先确认其单位、方向和离散精度；必要时将曲面转换为网格曲面。

需要新建坐标系时，在 **模型 > Frame** 菜单中选择即可直接创建一个默认坐标系节点，无需额外确认对话框。

模型、场景节点和轨迹可以分别保存或导出。工程文件用于保存完整场景；节点导出适合在其他工程复用单个设备或几何对象。

## 2. 规划铺层

在 **功能 > 铺层规划器** 打开铺层规划器。规划器的基本输入为：

- 铺层曲面；
- 铺放区域边界；
- 可选的引导曲线；
- 参考点和接缝；
- 铺层组、铺层节点以及规划参数。

规划方法包括 **固定角度**（`FixedAngle`）、**自然曲线**（`Natural`）、**平行偏移**（`CurveOffset`）、**切片**（`Slicing`），以及 **固定角度-平行偏移**（`FixedAngle_Parallel`）和 **自然曲线-平行偏移**（`Natural_Parallel`）组合方法。**可变角度**（`Variable`）选项可以让铺放角度沿参考线按函数变化；启用后需要填写**变角度函数**。

操作顺序通常是：

1. 选择或创建铺层组和铺层。
2. 设置铺层曲面、参考点、边界、引导曲线和接缝。
3. 选择规划方法与铺放角度，必要时启用可变角度。
4. 点击 **新建规划器** 初始化规划器。
5. 使用向右/向左计算按钮生成课程，或使用单步按钮逐组检查。
6. 观察场景树和 3D 视图中的参考线、课程、丝束及错误信息。
7. 通过 **修改铺层参数** 修改参数后重新计算。

边界必须是闭合曲线或闭合拓扑边界；引导曲线可以覆盖初始参考曲线。规划完成后，再在铺层属性中进行覆盖率、转向半径、铺放角度和点选查询。

## 3. 检查和编辑铺层

铺层节点可以控制整组丝束的显示，包括中心线、边界和 Tow 网格。Tow 节点可以单独修改显示和起止点，也可以用中心线、左边界或右边界对铺放区域进行分割。

对铺层进行手动修改后，应重新检查：

- 是否存在过短丝束、断裂或重叠；
- 转向半径是否满足材料和设备要求；
- 铺放角度误差是否在允许范围内；
- 课程边界和相邻课程间隙是否符合工艺要求。

## 4. 配置运动系统

在场景中准备机器人、工具、轨道、位置机和工件，并确认父子层级、基坐标系、法兰、TCP 以及碰撞几何正确。0.21.x 版本提供位置机、轨道和工具的 URDF 生成面板，也支持通用模型和 URDF 导出，适合先建立可复用的设备模型。

必要时使用 **工件位姿标定** 标定工件位姿，使用 **TCP 标定** 标定工具中心点。位姿格式、复制粘贴和标定结果说明见[位姿与标定](../advanced/pose_calibration.md)。

## 5. 仿真与导出

在 **功能 > 仿真及后处理** 打开面板：

1. 选择轨道、机器人、位置机和工具。
2. 添加需要仿真的轨迹节点，或使用 **自动选择** 根据场景树自动选择。
3. 选择运动学算法和轨道/位置机策略，点击 **应用**；需要统一设置时使用 **应用到所有轨迹**。
4. 设置仿真速度，使用 **开始**、**暂停**、**继续** 和 **停止** 检查运动过程。
5. 选择后处理脚本、导出路径、参考节点和是否按铺层分别导出。
6. 点击 **导出** 生成程序，并在目标控制器或离线仿真中验证。

导出的轨迹点包含轨迹段边界标记，后处理模板可以使用这些标记区分课程或路径段。KRL 模板的自定义方式见[后处理定制](../advanced/post_process.md)。

## 6. 设备与几何检查

- **碰撞检测**：配置碰撞检测对象并检查机器人、工具、工件和设备之间的干涉。
- **凸分解**：为支持的模型生成凸分解部件，改善碰撞或物理计算使用的几何。
- **变位机/导轨/工具 URDF 生成器**：从可视和碰撞几何创建通用设备节点。
- **测量**：在 3D 视图中测量几何数据。

发生计算失败时，先查看 **日志** 面板，确认节点类型、单位、坐标系和几何是否满足当前操作的输入要求。
