# 旋转生成丝束组

!!! note "适用版本"
    本功能在 v0.25.0 之后的 develop 分支新增，v0.25.0 安装包尚不包含。

适用于弹头、封头圆柱等回转零件：先规划一个 Course，再绕零件轴线生成同一铺层中的其他丝束组。源 Course 可以包含多根 Tow；每根 Tow 的中心线、左右边界和 Course 参考路径都会旋转，不要求一组只有一根带。

## 操作步骤

1. 规划并检查源 Course。
2. 创建沿零件旋转轴的**直线段节点**。线段起点到终点定义正向，角度按右手规则。
3. 右键源 Course，选择 **旋转生成丝束组**。
4. 在场景树选中直线段，点击 **旋转轴** 旁的 **设置**。
5. 检查 **铺放网格**。通常自动选择源铺层所在的网格；若铺层不在网格节点下，选择对应的实际网格实例再设置。
6. 选择按总数量或角度步长分布，设置旋转范围与曲面容差。
7. 点击 **预览** 检查结果，点击 **生成** 插入源 Course 后方。

对话框打开时仍可选择场景节点。关闭或修改参数会清除临时预览；生成时根据最新数据和节点位姿重新计算。撤销/重做作用于整批结果。

## 数量和角度

- **按总数量**包含原始 Course。完整一圈不重复生成 360°：总数量为 12 时新增 11 组，相邻间隔 30°。不足一圈时包含范围终点。
- **按角度步长**只生成范围内完整步长，不额外补齐不足一个步长的末段。
- 负旋转范围表示反向。单批总数最多 1000 组，含原始 Course。

## 坐标和结果

软件读取直线段的世界坐标原点和方向，再转换到所选网格局部坐标系，旋转所有路径并投影回原网格。网格必须是源铺层实际使用的网格，Course 与网格显示坐标系必须一致。

新 Course 保留丝束顺序、索引、材料尺寸、裁剪区间及最短长度/间隙设置。每组结果拥有独立数据，并从数据创建新的显示节点；修改副本不会修改原始组或其他副本。

曲面容差控制顶点和自适应中点采样处的投影检查，不是连续曲面误差或无重叠保证。网格查询使用单精度；投影失败或路径退化会拒绝整批插入。端头附近应检查间距和重叠，等角度分布不等于等曲面距离，也不会自动裁去重叠。

新建 Course 继续使用现有铺层轨迹、仿真及后处理流程。端头的变位机控制见[Lua 自定义变位机策略](../advanced/positioner_lua.md)。
