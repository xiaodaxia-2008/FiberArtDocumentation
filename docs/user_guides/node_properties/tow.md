# 丝束(Tow)属性

在场景树中找到要修改属性的预浸带节点，双击打开其属性编辑面板。

## 长度

显示该丝束的总长度（单位：米）。

## 分段

在定义了孔洞边界的铺放曲面上，一条预浸带会包含多段丝束，这里用来指定修改哪一段丝束。

## 修改起点

修改当前分段的起点，该值是起点距离参考中心线起点的弧长距离（单位：米）。如要延长0.1m，将该值减少0.1，否则，反之。

## 修改终点

修改当前分段的终点，该值是终点距离参考中心线起点的弧长距离（单位：米）。如要延长0.1m，将该值增加0.1，否则，反之。

## 优化

在某些情况下，延长了一段丝束后，可能导致相邻的丝束互相重叠，点击**优化**后，可以将相邻的重叠丝束进行合并。

## 删除分段

删除当前分段。删除前会弹出确认对话框，删除操作不可撤销；每条丝束至少需要保留一个分段。

## 显示

丝束节点的显示属性可以在场景树属性编辑器中修改：

- 显示纱线网格：控制该丝束的网格显示，铺层节点也可以统一控制其子 Tow 的网格显示；当子节点继承铺层显示设置时，应优先从铺层节点调整；
- 显示中心线：控制该丝束中心线的显示；
- 显示边界线：控制该丝束左、右边界线的显示；
- 显示方向：控制该丝束路径方向箭头的显示。

丝束节点还支持以下操作：

- 提取左边界线 / 提取中心线 / 提取右边界线：将丝束的左边界线、中心线或右边界线提取为一条独立的曲线节点。
