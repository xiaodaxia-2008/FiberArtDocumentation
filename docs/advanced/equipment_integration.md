# 设备与控制器集成

本页补充 v0.25.0 的设备工作流；新增 Course 旋转和变位机 Lua 功能另按 develop 标注。

## 设备模型编辑

统一 URDF 编辑器支持机器人、导轨、变位机及工具的树形结构编辑。可导入已有 URDF，编辑关节原点、方向、当前值、限位及连杆几何，再应用/重新加载。模型级基座位姿描述安装位置。机器人按结构选择 OPW 或对应轴数的龙门运动学，核对 TCP 和轴方向后再验证。

可视几何与碰撞几何分别设置，导出时分别选择是否包含网格；需要检查碰撞的设备应提供对应几何。OPW 图示辅助核对参数及轴方向，不能代替实际尺寸校验。

## 机床配置导出

右键仿真组选择 **导出配置（Export Configuration）**，生成 `.zmachine` 机床包。包用于传递设备运动学、安装关系和坐标系，默认轻量化，不包含网格。导轨上的机器人以导轨法兰为安装父级，随导轨或变位机的用户坐标系保留动态父级关系；不要将当前外部轴值重复烘焙为安装偏移。

导出后在接收控制器配置工具中检查轴地址、关节限位、基座/TCP 和坐标表，配置导出不等于已经下发到控制器。

## 数控数字孪生

打开数控数字孪生面板，选择空闲的仿真组，配置控制器 `ws://` 或 `wss://` 地址。连接获得轴信息后配置远端轴与本地关节映射及单位/标定，再开始同步。配置保存在仿真组中，需保存场景。

同一远端轴不能重复映射；单位和标定必须匹配。断线、遥测超过一秒未更新、远端轴信息变化或文档切换时停止同步，模型保留最后有效位置。该面板将反馈同步到模型，不代替控制器运动指令。

## 后处理协作

后处理支持 `.jinja` 与 Python，新增汇川扫描相机及纳博特机器人输出程序。后处理本地 MCP 服务可供外部工具读取/复用面板导出上下文；使用当前仿真组、轨迹、参考节点和导出路径，不能绕过这些必要配置。详见[后处理定制](post_process.md)。
