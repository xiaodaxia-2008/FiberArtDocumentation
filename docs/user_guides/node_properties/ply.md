# 铺层(Ply)属性

在场景树中找到要修改属性的铺层节点，双击打开其属性编辑面板。面板包含**参数与路径**、**导出铺层形状**、**覆盖分析**、**转向半径**、**铺放角度**、**压辊变形分析**和**点选查询**共七个页面。

## 参数与路径

### 连接路径策略

选择相邻两组铺放路径之间的过渡路径如何生成，共九种策略，参见[路径连接策略](../plan_parameters.md#link-path-policy)：

- 直线（`Straight`）
- 关节直线（`StraightJointSpace`）
- 偏移铺放曲面上的最短路径（`OffsetShortestPathOnLayupSurface`）
- 偏移铺放曲面上的投影路径（`OffsetProjectedPathOnLayupSurface`）
- 包络面上的最短路径（`ShortestPathOnEnvelope`）
- 包络面上的投影路径（`ProjectedPathOnEnvelope`）
- 回退铺放路径（`ReverseCurrentHeadPath`）
- 双向铺放（`ReverseNextHeadPath`）
- 双向铺放关节空间连接（`ReverseNextHeadPathJointSpaceLink`）

### 设置包络面

当连接路径策略选择**包络面上的最短路径**或**包络面上的投影路径**时，点击`设置包络面`，从场景树中选择一个包络面节点。如果修改了包络节点，需要重新设置。

### 修改更多参数

打开该铺层独立的铺层规划参数编辑器，参见[如何修改铺层参数](../plan_parameters.md#how-to-modify-ply-parameters)。

## 导出铺层形状

点击`导出为`将铺层形状导出为文件，支持 `gltf(*.gltf)`、`ply(*.ply)`、`stl(*.stl)` 和 `Step文件(*.step)` 格式。

- 单位：导出文件使用的长度单位，支持 M（米）和 MM（毫米）。单位设置仅在导出格式是 step 的时候有用。

## 覆盖分析

统计铺层覆盖铺放区域的百分比，以及铺层的面积、长度等。

- 采样点数：在铺放区域内进行随机采样统计的点的数量，范围为1000~1000000，步长1000，默认10000；
- 点击`分析`后输出：
    - 铺放区域内铺层占比：铺层覆盖铺放区域的百分比；
    - 铺放区域面积：铺放区域的表面积；
    - 铺层总面积：铺层所有丝束的面积和；
    - 铺层总长度：铺层所有丝束的长度和。

## 转向半径

分析每根预浸带的转向半径，可以以"x"（十字交叉）或者热力图的风格进行显示。

- 计算步长：沿丝束路径采样分析的间隔，默认0.03m；
- 显示风格：
    - 十字交叉 X：在转向半径小于阈值的采样点处显示"x"标记，提示该处转向过急；
    - 热力图：将转向半径按热力图颜色显示在丝束路径上；
- X显示阈值：使用十字交叉显示时，转向半径小于该值的采样点会被标记（`< 阈值m`）；
- 热力图下限 / 热力图上限：使用热力图显示时，映射到最小/最大颜色的转向半径值；
- 点击`计算`后，在最小转向半径中显示整层所有丝束中计算得到的最小转向半径。

## 铺放角度

分析预浸带的铺放角度与参考角度的误差，可以以"x"或者热力图的风格进行显示。

- 计算步长：沿丝束路径采样分析的间隔，默认0.03m；
- 显示风格：
    - 十字交叉 X：在角度误差超过阈值的采样点处显示"x"标记；
    - 热力图：将角度误差按热力图颜色显示在丝束路径上；
- X显示阈值：使用十字交叉显示时，角度误差大于该值的采样点会被标记（`> 阈值°`），默认5°；
- 热力图下限 / 热力图上限：使用热力图显示时，映射到最小/最大颜色的角度误差值；
- 点击`计算`后，在最大角度偏离中显示整层所有丝束中计算得到的最大角度偏离。

## 压辊变形分析

分析铺放过程中压辊接触丝束产生的变形量，可以以"x"或者热力图的风格进行显示。

- 计算步长：沿丝束路径采样分析的间隔，默认0.03m；
- 显示风格：
    - 十字交叉 X：在变形量超过阈值的采样点处显示"x"标记；
    - 热力图：将变形量按热力图颜色显示在丝束路径上；
- X显示阈值：使用十字交叉显示时，变形量大于该值的采样点会被标记（`> 阈值m`），默认0.005m；
- 热力图下限 / 热力图上限：使用热力图显示时，映射到最小/最大颜色的变形量值；
- 点击`计算`后，在最大变形量中显示整层所有丝束中计算得到的最大变形量。

## 点选查询

用鼠标在铺层上进行点击，查询点击处的坐标，以及所属铺层、组、预浸带和转向半径、铺放角度等信息。

使用方式：

1. 点击`拾取点`，然后在 3D 视图中点击铺层上一点，坐标显示在 X、Y、Z 中；
2. 点击`点选查询`，查询结果在下方文本框中显示。

## 显示

铺层节点的显示属性可以在场景树属性编辑器中修改：

- 显示纱线网格：控制整个铺层的 Tow 网格显示，关闭后可以只保留中心线或边界线，减少大型工程的显示负担；修改后重新打开工程时，检查显示状态是否符合当前观察需要；
- 显示路径：是否显示铺放路径；
- 显示方向：是否显示路径上各点的运动方向；
- 显示姿态：是否显示路径上各点的姿态坐标系；
- 显示命令：是否显示路径上的命令；
- 显示注释：是否显示路径上的注释；
- 仿真时显示位姿：仿真时是否显示实时位姿；
- 仿真时记录并显示路径：仿真时是否记录并显示轨迹路径。

铺层节点还支持以下操作：

- 修改参数：打开该铺层的铺层规划参数编辑器；
- 复制：复制该铺层及其下的所有课程、丝束；
- 显示左边界 / 显示右边界：将铺层的左/右边界提取为一条独立的曲线节点。
